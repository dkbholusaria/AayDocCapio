What it does

🔐 Encrypted Credential Vault

PAN, DOB, and portal passwords stored locally using PBKDF2HMAC + Fernet AES-128. Nothing leaves your machine.

📑 Bulk Download

Download Form 26AS (PDF + TXT), AIS (PDF), and TIS (PDF) for multiple clients in one click.

🔓 Auto PDF Unlocking

Downloaded PDFs are automatically unlocked using PAN and DOB — open immediately without passwords.

📊 Live Batch Progress

Per-client real-time status popup with step-by-step logs. Stop mid-batch at any time.

📥 Excel / CSV Import

Bulk-import assessees from Excel or CSV. Generate a pre-formatted import template in one click.

🌐 Headless by Default

Browser runs invisibly in the background for speed. Toggle "Show Browser" for step-by-step debugging.

How to get started

Download & Install

Run AayDocCapio_Setup_v1.0.0.exe. The wizard installs the app and downloads the Chromium browser engine automatically (one-time, ~150 MB).

Add your clients

Use the Single Profile tab to add clients manually, or use Bulk Operations → Import CSV / Excel to load multiple assessees at once.

Select Assessment Year & Output Folder

Pick the Assessment Year from the dropdown and set your preferred output directory.

Select clients and click Run

Tick the clients you want, click ▶ Run, and choose Download 26AS or Download / Request AIS & TIS. A live progress popup tracks every client.

Collect your files

Downloaded PDFs are saved to <Output Directory>/<PAN>-<Name>/AY_<year>/ and auto-unlocked — ready to use immediately.

⚠️ AIS/TIS require Google Chrome. Form 26AS works without it. Make sure Chrome is installed before downloading AIS or TIS.
✅ Large AIS files? If the ITD server queues your AIS, AayDocCapio notifies you. Wait ~5 minutes, then use Download Previously Requested AIS to fetch it automatically.

Common questions

Is my data safe? Where are credentials stored?

All credentials (PAN, DOB, portal password) are stored in an encrypted local file tax_vault.json on your machine using PBKDF2HMAC + Fernet AES-128 encryption. Nothing is sent to any server — the app only communicates directly with the official ITD e-Filing portal.

Why does AIS/TIS require Google Chrome?

The Insight/AIS portal's download buttons only fire correctly in real Google Chrome. Playwright's bundled Chromium does not trigger the download event on that portal. Form 26AS works fine with either.

What does "AIS request queued" mean?

When an AIS file is large, the ITD server queues its generation. AayDocCapio will show a notification with a reference number. Wait ~5 minutes, select those clients again, and click Download Previously Requested AIS.

Can one client's failure stop the whole batch?

No. Each client is isolated — if one fails (e.g. wrong password, portal timeout), the reason is shown in the progress popup and the batch continues for the remaining clients.

Can I use this without installing it?

Yes. The portable folder dist\AayDocCapio\ from the build can be zipped and run directly without installation. For most users the installer is easier.
