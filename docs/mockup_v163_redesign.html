Features

Everything you need — from bulk downloads to client delivery

📑

26AS, AIS and TIS Downloads

Saves hours of manual portal logins per client

Download Form 26AS PDF + TXT, AIS PDF, and TIS PDF for all selected clients in a single sequential batch — with instant or queued AIS generation.

🔐

Encrypted Credential Vault

Client PANs & passwords never leave your machine

PAN, DOB, portal passwords, and email addresses stored locally in tax_vault.json with PBKDF2HMAC + Fernet AES-128. No cloud sync or telemetry.

🔓

Auto Unlocking

No more manual password entry for every PDF

PDFs and 26AS TXT ZIPs are unlocked automatically using PAN and DOB-derived passwords, with clear warnings if the DOB on record is wrong.

📊

Live Batch Progress

Know exactly which client succeeded or failed in real time

Per-client real-time status for downloads — conversion state, saved-folder links, Stop control, and step-by-step logs.

📘

26AS Excel Workbook

Structured data — ready for review without opening PDFs

Auto-converts 26AS TXT into structured Excel + HTML — Assessee Details, Part I–IX sheets, summary links, and large-file streaming for 200K+ row files.

📊

AIS JSON → Excel Workbook

Capital gains auto-computed — no manual formula work

Convert a downloaded AIS JSON into a structured Excel workbook — one sheet per income/transaction category, plus a Capital Market (All) consolidated sheet that auto-computes STCG, LTCG, and Section 55(2)(ac) grandfathering adjustments.

📥

Excel / CSV Import & Export

Onboard a full client list in minutes, not hours

Bulk-load assessees from Excel or CSV including Email and CC columns. Export client data or generate a pre-formatted import template in one click.

📧

Mail Docs to Clients

Eliminate the step of manually attaching & sending each document

Batch-email AIS, TIS and 26AS files directly to clients in one click. Scan your download folder, match PANs, pick recipients, and send — with per-row live status.

✉️

All Major Email Providers

Works with your existing email — no new account needed

One-click presets for Gmail, Outlook.com, Microsoft 365 / Office 365, Exchange, Yahoo Mail, iCloud and Custom SMTP — auto-fills host, port and encryption.

✍️

Rich Text Email Composer

Professional, personalised emails without typing each one

Font, size, Bold / Italic / Underline toolbar, CC and BCC fields. Smart placeholders: {client_name}, {pan}, {ay}, {documents} — render as a numbered list of actual attached files.

🗂️

Status and History

Always know what was downloaded and when, per client

Filter by download status and review the last result and saved location per client, per AY/FY. Email activity logged with session dividers and per-client audit trail.

📅

AY / TY / FY Management

Handles multi-year filing without re-configuration

Add, remove, reorder and toggle assessment, tax, and financial year entries from Settings — output folders are consistently labelled to match.

🌗

Themes and Headless Mode

Comfortable for long sessions; handles CAPTCHA when needed

Light and Dark Navy themes with preference saved across sessions. Browser automation runs hidden by default — switch to visible mode for CAPTCHA handling.

Mockup Summary

What changed and why

👥

Audience Badges NEW

Adopted from TallyPrime's persona chip system

Five role chips (CA, Tax Professional, CA Firm, Tax Consultant, Finance Team) appear below the hero tagline. Visitors self-identify in under 2 seconds — they know this tool is for them before they read a word.

🗂️

Tabbed Features NEW

Adopted from TallyPrime's segmented feature interface

13 cards reorganised into 4 tabs: Downloads, Excel Reports, Email Delivery, Manage & Settings. A CA who only cares about downloads doesn't wade through email composer details. Tabs also leave room to grow without the page feeling cluttered.

💡

Benefit Chips NEW

Adopted from TallyPrime's feature→benefit pairing

Each feature card now has a short blue chip above the description that answers "what problem does this solve?" — e.g. "Capital gains auto-computed — no manual formula work". Converts feature descriptions into value propositions.

Production note Everything else (hero gradient, download buttons, How it works, Screenshots, Security table, FAQ) stays unchanged from the current index.html. Only the hero badge row, features section, and card layout need to change.
