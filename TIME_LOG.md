# Time Log

**Methodology:** session duration is the span between the first and last git commit timestamp on a given work date — an honest lower-bound proxy for active time, not a precise stopwatch. Undercounts sessions with long gaps between commits (research, thinking time); overstates nothing, since it never counts time before the first or after the last commit of the day.
