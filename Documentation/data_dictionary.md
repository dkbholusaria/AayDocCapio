# Data Dictionary

Describes every data file AayDocCapio reads and writes at runtime.

---

## 1. `tax_vault.json`

Stored next to `app.py` (source runs) or next to the `.exe` / inside the app bundle (frozen builds). Never committed to version control.

### Top-level structure

```json
{
    "assessees": [ ... ],
    "settings":  { ... },
    "download_history": { ... }
}
```

---

### 1.1 `assessees` array

Each element is one client record.

| Field | Type | Description | Example |
|---|---|---|---|
| `id` | string (UUID4) | Stable internal identifier. Never changes even if PAN/name is edited. | `"a3f1b2c4-..."` |
| `name` | string | Client's full name as stored in the vault. 2+ chars. | `"Rajesh Kumar"` |
| `pan` | string | PAN in uppercase, exactly 10 chars. Format: `[A-Z]{3}[PCHFATBLJG][A-Z][0-9]{4}[A-Z]`. | `"AAAPT0001A"` |
| `dob` | string | Date of birth in `DD-MM-YYYY`. Used to derive PDF/ZIP unlock passwords. | `"06-07-1974"` |
| `password_enc` | string | Portal password encrypted with Fernet (AES-128). Decrypted only in memory immediately before use. | `"gAAAAAB..."` |

**Uniqueness:** PAN is the natural key. `add_update_assessee()` upserts by PAN when no `id` is supplied.

**Password derivation note:** The 26AS TXT is delivered inside a ZIP whose password is `DDMMYYYY` (DOB without separators). AIS/TIS PDFs use a combination of PAN and DOB. Both are derived from `dob` at download time — a wrong DOB means the files cannot be unlocked automatically.

---

### 1.2 `settings` object

Key/value pairs persisted across sessions. All keys are optional; the app falls back to defaults if absent.

| Key | Type | Default | Description |
|---|---|---|---|
| `output_dir` | string | Platform Downloads folder | Root directory where downloaded files are saved |
| `selected_ay` | string | First active AY | The Assessment Year label selected in the UI dropdown |
| `headless` | boolean | `true` | Whether the browser runs hidden |
| `theme` | string | `"light"` | Active UI theme. Values: `"light"`, `"dark_navy"` |
| `ay_label_mode` | string | per-AY config | Override for AY/TY/FY label display mode |

---

### 1.3 `download_history` object

Records the last known download result per client per Assessment Year. Keyed by PAN (uppercase), then by AY label.

```json
"download_history": {
    "AAAPT0001A": {
        "AY 2025-26": {
            "status": "✅ 26AS Downloaded",
            "path":   "C:\\Users\\CA\\Downloads\\AAAPT0001A-Rajesh Kumar\\AY_2025-26",
            "ts":     "11-Jun-2026 14:32:05"
        }
    }
}
```

| Field | Type | Description |
|---|---|---|
| `status` | string | Last status string shown in the Batch Progress dialog |
| `path` | string | Absolute path to the client's AY subfolder |
| `ts` | string | Timestamp of the last download attempt (`DD-Mon-YYYY HH:MM:SS`) |

## 2. `assessment_years.json`

Edited via **Settings → Manage Years**. Contains the list of AY/TY/FY entries available in the dropdown.

```json
[
    { "label": "AY 2025-26", "type": "AY", "active": true },
    { "label": "AY 2024-25", "type": "AY", "active": true },
    { "label": "FY 2024-25", "type": "FY", "active": true }
]
```

| Field | Type | Description |
|---|---|---|
| `label` | string | Display string shown in the dropdown and used as the key in `download_history` |
| `type` | string | `"AY"` (Assessment Year for 26AS), `"TY"` (Tax Year), or `"FY"` (Financial Year for AIS/TIS) |
| `active` | boolean | Whether this entry appears in the dropdown |

**Relationship to filenames:** The AY label is used to construct output subdirectory names (`AY_2025-26`) and appears in the Batch Progress dialog header.

---

## 3. Output file naming convention

Files are saved under `<output_dir>/<PAN>-<Name>/AY_<year>/`.

| Document | Filename pattern | Example |
|---|---|---|
| 26AS TXT | `<PAN>-26AS-<AY>.txt` | `AAAPT0001A-26AS-2025_26.txt` |
| 26AS PDF (unlocked) | `<PAN>-26AS-<AY>.pdf` | `AAAPT0001A-26AS-2025_26.pdf` |
| AIS PDF | `<PAN>-AIS-<FY>.pdf` | `AAAPT0001A-AIS-2025_26.pdf` |
| TIS PDF | `<PAN>-TIS-<FY>.pdf` | `AAAPT0001A-TIS-2025_26.pdf` |

Note: year separators use `_` in filenames (e.g. `2025_26`) to keep paths valid on all platforms.

---

## 4. Log files

| File | Location | Contents |
|---|---|---|
| `app.log` | Next to `app.py` / exe | Full structured run log including step-by-step automation traces |
| `startup_diag.log` | `%LOCALAPPDATA%\AayDocCapio\` (Windows) / `~/.local/share/AayDocCapio/` (Linux) | 8-step startup probe written before Qt initialises; used to diagnose silent crashes |

Both log files contain **no credentials**. PAN numbers are masked as `PAN[:3]XXXXXXX` throughout.

## 5. Import template columns

Used by **Client Master → Import Excel/CSV** and generated by **Export Template**.

| Column | Required | Validation | Example |
|---|---|---|---|
| `Name` | Yes | 2+ chars | `Rajesh Kumar` |
| `PAN` | Yes | 10-char PAN format | `AAAPT0001A` |
| `DOB` | Yes | Any recognised date format; normalised to `DD-MM-YYYY` | `06-07-1974` or `1974-07-06` |
| `Password` | Yes | 4+ chars | `Portal@2024` |

Accepted DOB formats: `DD-MM-YYYY`, `DD/MM/YYYY`, `DD.MM.YYYY`, `YYYY-MM-DD`, `YYYY/MM/DD`, `DD-Mon-YYYY`, and Excel date serials (auto-converted by openpyxl).
