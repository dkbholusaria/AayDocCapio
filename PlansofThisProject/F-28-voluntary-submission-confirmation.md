# F-28: Add voluntary submission confirmation to issue templates

GitHub issue: https://github.com/dkbholusaria/AayDocCapio/issues/36

## Goal

Strengthen the mandatory issue-template acknowledgement by stating that the
reporter is submitting the bug report or feature request voluntarily.

## Plan

1. Update `.github/ISSUE_TEMPLATE/bug_report.yml`.
2. Update `.github/ISSUE_TEMPLATE/feature_request.yml`.
3. Keep the DPDP-aligned personal-data language.
4. Add voluntary-submission wording.
5. Keep the checkbox mandatory.
6. Verify with `git diff --check`.

## Proposed wording

I am submitting this request voluntarily and confirm this submission does not
contain personal data as defined under the Digital Personal Data Protection Act,
2023, including PANs, passwords, taxpayer records, or any other confidential
information.
